# AI VoiceOver Data - Vanilla RU

**Version:** 1.1.2

Единый модуль озвучки для английского клиента OctoWoW и совместимых клиентов Vanilla 1.12. Английские таблицы находят правильный квест по тексту интерфейса, после чего модуль выбирает русскую запись.

## Приоритет аудио

```text
совместимый CatQuest
→ текущая русская озвучка
→ английский fallback
```

CatQuest используется только для проверенных описаний и сдач. Остальные квесты, progress и gossip продолжает обслуживать текущая RU/EN-база.

## Установка через GitAddonsManager

Один раз добавьте два HTTPS URL:

```text
https://github.com/Alukarho/AI_VoiceOver.git
https://github.com/hneis/AI_VoiceOverData.git
```

GitAddonsManager должен создать:

```text
Interface/AddOns/AI_VoiceOver/AI_VoiceOver.toc
Interface/AddOns/AI_VoiceOverData/AI_VoiceOverData.toc
```

После установки или обновления аудио полностью перезапустите игру. `/reload` недостаточно, если появились новые звуковые файлы.

В дальнейшем достаточно нажимать `Update All` в GitAddonsManager.

Первоначальное клонирование data-репозитория загружает около 2 ГиБ Git-объектов и создаёт примерно 1.7 ГиБ рабочих файлов. Предусмотрите не менее 4 ГиБ свободного места. Git LFS не используется, поскольку Qt GitAddonsManager его не поддерживает. Последующие обновления получают только новые Git-объекты, но заменённые записи остаются в истории.

## Диагностика

```text
/voru
/voru 5-accept
```

Первая команда показывает количество выбранных CatQuest, RU и EN маршрутов. Вторая показывает источник, длительность и фактический путь конкретной записи.

Vanilla 1.12 не сообщает аддону, что отдельный OGG был удалён или не открылся. Если `/voru <ключ>` показывает CatQuest-путь, но звука нет, выполните Repair/Reclone этого аддона в GitAddonsManager и полностью перезапустите игру. Автоматический переход на RU после локального повреждения уже выбранного CatQuest-файла невозможен.

## Обновление CatQuest

Новая версия CatQuest не подключается вслепую. Архив проверяется, тексты повторно сравниваются с Octo, после чего внутрь модуля копируются только совместимые записи.

GitHub автоматически проверяет CurseForge каждые 12 часов и создаёт черновой audit PR для нового file ID. Гигабайтный архив и внешние текстовые базы обрабатываются локально; публикация и слияние остаются ручными.
